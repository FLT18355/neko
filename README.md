# neko

一个跑在终端里的本地音乐播放器。界面支持六套 Catppuccin 风格主题和五彩强调色，播放交给 mpv，操作以单键和鼠标为主。

![terminal](https://img.shields.io/badge/interface-terminal-1e1e2e) ![palette](https://img.shields.io/badge/palette-catppuccin%20mocha-f5c2e7)

## 依赖

- Rust 1.85+（edition 2024）
- `mpv`（播放后端，需要能从 `PATH` 找到）
- 带 Nerd Font 图标的等宽字体，例如 JetBrainsMono Nerd Font

```bash
# Arch
sudo pacman -S mpv
```

## 构建与安装

```bash
cargo build --release
install -m755 target/release/neko ~/.local/bin/neko
```

也可以直接运行：

```bash
cargo run --release -- ~/音乐
```

## 使用

```bash
neko                              # 使用配置里的音乐目录列表
neko ~/音乐                       # 指定一个目录，并记为默认目录
neko ~/音乐 ~/下载/音乐           # 多个目录合并成一个曲库
neko --transparent ~/音乐         # 本次启动使用透明背景
neko --help
neko --version
```

第一次启动时如果配置为空，会自动选择 `~/音乐`，不存在则尝试 `~/Music`。之后按 `o` 管理音乐目录：列表里按 `a` 添加、`x` 移除、`r` 重新扫描。目录列表会写入配置文件；旧版单目录配置会在启动时自动迁移。

## 鼠标

- 悬停：标签、曲目行、控制栏、设置项、队列行都会高亮，底部显示对应提示。
- 单击曲目行选中，再点一次播放；单击标签切换视图；单击「文件夹」打开目录选择，单击「分类」打开专辑 / 艺术家浏览。
- 单击进度条跳转到对应位置；单击两侧 `-5s` / `+5s` 微调。
- 单击或拖动音量条调节音量；悬停后滚轮也能调整。
- 单击时间文字切换「已播放 / 剩余」。
- 控制栏可点击：上一首、播放/暂停、下一首、模式、随机、收藏、搜索、队列、设置、帮助、退出。
- 滚轮滚动曲目列表；在帮助、队列、设置、分类浏览等弹窗里滚动内容。
- 弹窗内的行、左右箭头和底部按钮都可以点击；队列行单击选中，双击播放。
- 单击弹窗外部关闭弹窗。

## 设置

按 `c` 打开设置页。`↑/↓` 选择，`←/→` 调整，`Enter` 修改，也可以直接用鼠标点每行右侧的 `‹` / `›`。

设置项包括：音乐目录（单个目录显示路径，多个目录显示数量）、音量、播放速度、播放模式、音效、均衡器、歌词开关、歌词偏移、排序方式、睡眠定时、A-B 循环、透明背景、时间显示、主题、断点续播、快捷键、音频设备、清空最近，以及配置文件和缓存文件的路径。目录、模式、音效、均衡器、歌词、排序、透明背景、时间显示、主题、断点续播、音频设备、歌单、收藏和自定义按键都会保存到配置文件。

## 配置文件与缓存

配置文件和缓存文件分开存放：

```text
# 配置
$XDG_CONFIG_HOME/neko/config.json
~/.config/neko/config.json          # 未设置 XDG_CONFIG_HOME 时

# 缓存
$XDG_CACHE_HOME/neko/cache.json
~/.cache/neko/cache.json            # 未设置 XDG_CACHE_HOME 时
```

配置保存音乐目录列表（`music_dirs`，兼容旧版 `music_dir` 字符串）、音量、模式、音效、均衡器开关与各段增益、歌词开关、排序方式、时间显示模式、主题、音频设备、断点续播开关、收藏、自建歌单和自定义按键。

缓存保存最近播放记录、上次播放的曲目和位置、上次视图、分类和搜索词、播放队列与位置、选中曲目、每首歌的播放次数、星级评分、断点位置、累计收听时长与每首歌的收听秒数。启动时会恢复上次播放队列；曲目以暂停状态载入，开启断点续播时按空格从上次位置继续。最近视图也直接读取缓存。播放速度不跨启动保留：每次启动都会回到 1.00x。

## 实现说明

- 播放、暂停、跳转、音量和模式都由 mpv 的 JSON IPC 完成，播放进度通过轮询 `time-pos` 和 `duration` 刷新。
- 队列使用临时 M3U 文件交给 mpv；切歌、循环和随机由 mpv 的播放列表控制。
- 歌词读取同名 `.lrc` 文件，支持 UTF-8、`[offset:]` 和一行多个时间戳。
- 终端界面使用 crossterm 管理原始输入和鼠标事件，界面内容由 ANSI 序列直接绘制。
- 主题颜色集中定义在 `src/theme.rs`，绘制层通过原子索引读取当前调色板，切换主题不需要重建界面；`accent()` 循环取强调色，`rainbow()` 生成渐变。
- 系统时间由 `src/clock.rs` 通过 `libc` 的 `localtime_r` / `localtime_s` 取本地时区，跨平台可用。
- 多目录扫描会按路径去重；分类和文件夹视图取最长的匹配根目录，嵌套目录不会被归到父级。
- 全局快捷键由 `src/keymap.rs` 定义默认绑定，配置里的覆盖项在启动时合并；弹窗内的编辑键仍是固定按键。
- 10 段均衡器把增益转换成 mpv 的 `lavfi=[equalizer=…]` 滤镜链；关闭均衡器时恢复音效预设。
- 音频输出通过 mpv 的 `audio-device-list` 读取，切换时写入 `audio-device` 属性。
- 队列编辑使用 mpv 的 `playlist-move` / `playlist-remove` / `playlist-clear`，更新后重新读取播放列表。
- 分类浏览按音乐目录的相对路径分组：艺术家取第一层目录，专辑取完整父目录；先进入分类再播放时只播放该分类内的曲目。
- 退出时把当前队列和位置写入缓存，启动时用暂停状态重新载入 mpv 播放列表，恢复过程不计入播放次数。
- 断点位置在切歌和退出时写入缓存；重新播放同一路径时按缓存位置跳转。
- 退出时发送 `quit` 给 mpv，并删除 socket 与临时 M3U。
